# openSA · 开源系统架构师

> 一个面向初中级工程师到架构师的中文架构师知识库与真实案例库。

## ✨ 特性

- 🎯 **五大能力维度**：设计 / 决策 / 沟通 / 工程 / 领导
- 🏛️ **真实案例库**：按行业、规模、主题多维索引
- 📈 **渐进式学习路径**：每章标注「入门 / 进阶 / 架构师」分级
- 🤝 **开源协作**：欢迎贡献

## 🌐 在线阅读

https://liangweidonggood.github.io/openSA/

## 🚀 本地构建

前置：Rust 工具链（[rustup](https://rustup.rs/)）

```bash
cargo install mdbook
git clone https://github.com/liangweidonggood/openSA.git
cd openSA/book
mdbook serve --open
```
